# 前端重做方案 · Operations Deck

## 一、先说结论

现有前端不是"难看"，是**没收口**。token 体系（`styles.css` 的 `:root`）、亮暗双主题、
表格的服务端筛选/密度/列视图/导出、StatusTag 语义色——这些底座都在，而且方向是对的。
问题全部集中在**执行层**：组件的布局细节、页面骨架的空间分配、图表选型。

所以这次不推翻 token，推翻的是**视觉执行与页面骨架**。把设计力气花在"每天盯 8 小时的人
是否顺手"上，而不是换一层皮。

## 三、设计方向

参考做得好的内部运营台（Flexport 内部台、project44、SAP TM 新版皮肤）的共同点，
提炼成四条本项目要落地的原则：

1. **表格即产品。** 这是运营人员 80% 时间待的地方。密度、列宽、行内操作的顺手程度，
   比任何视觉效果都重要。
2. **用"层"建立层级，不用"框"。** 背景色阶（`--bg` → `--panel` → `--panel-2`）+ 排版权重
   来分组，而不是给每一块都套一圈边框。边框多了，页面就碎了。
3. **数字优先。** 关键数字大字号 + 等宽数字（`tabular-nums`）+ 弱化标签。
   运营看的是数，不是标签。
4. **颜色只承担语义。** 红/琥珀/绿/蓝只用于状态与风险，装饰性渐变收敛到品牌位
   （logo、主按钮、登录页），其余地方一律不用。

## 四、实施顺序（按杠杆从大到小）

### A. 表格引擎重做（`DataTable.tsx` + `styles.css` 的 `.dt-*`/`.table`）
- **修掉重叠**：操作列改 `position: sticky; right: 0`，独立背景，不再与内容列争空间
- **列宽策略**：数字/金额列定宽右对齐 + `tabular-nums`；文本列弹性；`white-space: nowrap` + 省略号
- **零信息列自动折叠**：整列同值时收进表头标注（"业务：全部整车"），不占列
- **行内操作 hover 显形**：常态只留最主要的一个动作，其余 hover 时滑出
- **行高**：紧凑 34px / 标准 40px / 舒适 48px，让「密度」按钮真正起作用
- **去斑马纹**，改 hover 高亮 + 选中行左侧 2px 色条
- 表头 sticky + 首列 sticky

### B. 页面骨架：`PageHeader` + 指标条
- 新增 `PageHeader` 组件：标题 / 副标题 / 关键指标内联 / 主操作，统一所有页面的顶部
- KPI 从「卡片行」改为「指标条」：一行横排，用竖分隔线，不用边框卡片 —— 省下 ~60px 垂直空间
- 去掉卡片右下角的装饰编号
- 空状态压缩为 `min-height: 200px`，不再独占半屏

### C. 视觉纵深（`styles.css` 全局）
- 背景三层：页面 `--bg` → 内容块 `--panel` → 嵌套 `--panel-2`
- 拆掉大部分 1px 边框，改用背景色差 + `--shadow-xs`
- 强调色只留在：主按钮、激活导航、关键数字、状态标签

### D. 图表重做（`BusinessMetrics.tsx` / `Sparkline.tsx`）
- **稀疏数据自动降级为柱状图**：非零点少于总点数 30% 时不画面积图
- 调色板改读 CSS 变量，亮暗主题自动跟随
- 补齐费用科目的中文名映射（`freight` → 运费）
- 空数据显示明确说明，不画一条 0 基线

### E. 门面（`LoginPage` / `ControlTowerPage` / `AppLayout`）
- 登录页左侧填上内容：品牌 + 价值主张 + 克制的运输网络图形
- 驾驶舱重排：顶部指标带 → 左（待办/异常/风险流）右（趋势/构成）分栏
- 侧栏与顶栏细节打磨

### F. 亮暗对齐与可读性
- 暗色下逐屏核对对比度，正文与表格数字 ≥ WCAG AA
- 保留 `prefers-reduced-motion` 降级

### G. 收尾
- 清理可见面与暗色下会露馅的硬编码颜色（`frontend/src` 有 600+ 处内联 style，
  引用 `var(--*)` 的会自动跟随主题，写死 hex 的不会）
- 窄屏降列

## 五、验证

1. `npx tsc --noEmit` + `npx vite build` 全绿
2. puppeteer 截图关键屏，**亮色与暗色各一遍**：登录 / 驾驶舱 / 订单管理 / 调度台 / 对账中心
3. 逐条核对第二节那张表，确认每个问题都消失
4. 重点回归：密集表格在两个主题下文字清晰、无重叠、滚动不卡

## 六、不在本次范围

- 不改后端与接口契约
- 不追求 600+ 处内联 style 全部清零（只清可见面与暗色露馅处）
